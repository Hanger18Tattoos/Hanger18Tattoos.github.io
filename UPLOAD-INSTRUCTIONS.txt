HANGER 18 TATTOOS — V15 FULL WEBSITE

1. Unzip Hanger18-Website-V15-Full-GitHub.zip on your Mac.
2. Open https://github.com/Hanger18Tattoos/Hanger18Tattoos.github.io
3. In the main branch (repository root), use Add file > Upload files.
4. Drag the entire docs folder. Confirm paths include docs/index.html, docs/v15-finishing.css, docs/assets/v15-storefront-silver-actual-sign.webp, and docs/assets/glen-portfolio/...
5. Commit changes directly to main. GitHub Pages should remain main > /docs.
6. When deployment completes, open https://hanger18tattoos.github.io/ and hard-refresh with Command + Shift + R.

IMPORTANT: Do not put docs inside another docs folder. No need to change the current DNS.
