2. Open GitHub account Hanger18Tattoos, repository Hanger18Tattoos.github.io.
3. Upload the entire docs/ folder to the repository root, replacing old files.
   You must end with docs/index.html (NOT docs/docs/index.html).
4. Commit changes to main.
5. In Settings -> Pages, ensure deployment is from main /docs.
6. After deployment, open https://hanger18tattoos.github.io/?v=23
