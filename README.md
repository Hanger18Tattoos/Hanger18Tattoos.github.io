# Hanger 18 Tattoos - V7 Gold Filigree

This is the full website build. It keeps the previous content and one-page layout. The header has exactly one fixed logo. The storefront is the approved darkened real storefront photo embedded as `assets/v7-approved-storefront.webp`.

Updates: original hand-built gold SVG filigree, small skull flourishes, warm gold-framed artist cards / gallery cards, engraved gold heading treatment, contrasting Cinzel and Great Vibes fonts. All copy and artist links are retained from V6.

## GitHub Pages install
Upload the `docs` DIRECTORY into the ROOT of `Hanger18Tattoos/Hanger18Tattoos.github.io`. In GitHub Settings > Pages, select Deploy from a branch, main, and `/docs`. The old root index.html will not be used. When you re-upload later, replace files inside `docs` rather than creating a second nested docs directory.

## Before moving the real domain
The five artist galleries still rely on public third-party image links for Sean, Dave, Glen and the shop archive. These are not all downloaded locally. Add authorized original artist photos and portfolios to assets and update `site-data.js`. Do NOT disconnect the old domain until all externally-hosted old-domain images are stored locally.
